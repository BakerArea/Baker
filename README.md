# 🛡️ Baker - Segurança no Trabalho

Um site profissional e completo sobre segurança ocupacional, desenvolvido com HTML5, CSS3 e JavaScript moderno.

## 📋 Descrição

Baker é uma plataforma educacional dedicada à promoção da segurança no ambiente de trabalho. O site oferece informações abrangentes sobre prevenção de acidentes, normas regulamentadoras, equipamentos de proteção individual (EPI) e boas práticas de segurança ocupacional.

## ✨ Características Principais

### 📚 Conteúdo Educacional
- **Pilares da Segurança**: Cobertura completa dos 6 pilares essenciais
  - Equipamento de Proteção Individual (EPI)
  - Identificação de Riscos
  - Normas e Legislação
  - Saúde Ocupacional
  - Treinamento e Capacitação
  - Investigação de Acidentes

### 🎯 Recursos Interativos
- Checklist diária de segurança
- Formulário de contato para denúncias
- Dicas práticas de segurança
- Estatísticas sobre acidentes de trabalho
- Navegação suave entre seções

### 📱 Design Responsivo
- Layout adaptável para desktop, tablet e mobile
- Interface intuitiva e amigável
- Cores profissionais e acessíveis
- Animações suaves e transições

### 🔐 Segurança
- Validação de formulários no cliente
- Tratamento seguro de dados
- Monitoramento de inatividade
- Boas práticas de codificação

## 🚀 Como Usar

### 1. Clonar o Repositório
```bash
git clone https://github.com/rindouhaetani-blip/Baker.git
cd Baker
```

### 2. Abrir o Site Localmente
```bash
# Opção 1: Abrir diretamente no navegador
open index.html

# Opção 2: Usar um servidor local (Python)
python -m http.server 8000

# Opção 3: Usar Live Server (VS Code)
# Instale a extensão Live Server e clique em "Go Live"
```

### 3. Acessar no Navegador
```
http://localhost:8000
```
